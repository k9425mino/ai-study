# CodeRabbit 사용 가이드

## CodeRabbit이란?

CodeRabbit은 Pull Request의 변경 내용을 분석해 요약, 인라인 리뷰, 잠재적 버그와 보안 문제, 개선 제안을 제공하는 AI 코드 리뷰 도구입니다. 정적 분석기의 규칙 검사와 달리 변경 맥락과 주변 코드를 함께 살피는 것이 특징입니다.

유용한 상황은 다음과 같습니다.

- 혼자 개발하거나 리뷰 인력이 부족한 소규모 팀
- 외부 기여가 많은 오픈소스 프로젝트
- 사람이 비즈니스 로직과 설계에 집중하기 전에 기본적인 문제를 걸러내고 싶은 팀
- AI가 만든 큰 변경을 구조적으로 파악해야 하는 리뷰어

## GitHub 저장소에 적용하기

### 1. GitHub App 설치

CodeRabbit에 GitHub 계정으로 로그인한 뒤 GitHub App을 설치하고 리뷰할 저장소를 선택합니다. 조직 저장소라면 설치 및 저장소 접근 권한을 가진 관리자의 승인이 필요할 수 있습니다.

### 2. 기본 동작으로 먼저 관찰

설정 파일이 없어도 자동 리뷰가 동작합니다. 처음부터 옵션을 많이 추가하기보다 몇 개의 실제 PR에서 다음을 관찰하는 편이 좋습니다.

- 유용한 코멘트와 불필요한 코멘트의 비율
- 자주 놓치는 프로젝트 고유 규칙
- 리뷰에서 제외할 생성물과 의존성 파일
- 자동 리뷰가 필요한 대상 브랜치와 Draft PR 정책

### 3. 필요할 때 설정 추가

저장소 루트에 `.coderabbit.yaml`을 추가하면 리뷰 언어, 강도, 자동 리뷰 범위, 파일 제외 규칙, 경로별 지침을 버전 관리할 수 있습니다. 자세한 내용은 [YAML 가이드](./03-yaml-guide.md)를 참고하세요.

### 4. PR 리뷰 확인

PR을 열면 CodeRabbit이 변경 요약과 리뷰 코멘트를 남깁니다. 새 커밋을 푸시하면 기본적으로 증분 리뷰가 이어지지만, 일정 횟수 이후 자동 리뷰가 일시 중지될 수 있습니다.

PR 코멘트에서 사용할 수 있는 대표 명령은 다음과 같습니다.

```text
@coderabbitai review
@coderabbitai full review
@coderabbitai pause
@coderabbitai resume
@coderabbitai resolve
```

- `review`: 마지막 리뷰 이후 변경분을 증분 리뷰합니다.
- `full review`: 기존 리뷰 상태와 무관하게 PR 전체를 다시 리뷰합니다.
- `pause` / `resume`: 자동 리뷰를 일시 중지하거나 재개합니다.
- `resolve`: CodeRabbit이 남긴 이전 코멘트를 정리합니다.

## 잘 활용하는 법

### 리뷰 결과와 대화하기

코멘트의 근거가 불명확하면 바로 수정하지 말고 재현 조건, 영향 범위, 대안을 질문합니다. CodeRabbit의 제안이 프로젝트 의도와 다르다면 그 의도를 설명해 후속 답변을 받습니다.

### 심각도에 따라 처리하기

먼저 버그, 보안, 데이터 손실 가능성처럼 머지를 막을 문제를 확인합니다. 리팩터링과 스타일 제안은 현재 PR의 목적과 비용을 고려해 별도 작업으로 미룰 수 있습니다.

### 사람 리뷰를 대체하지 않기

AI는 일정, 제품 요구사항, 도메인 배경, 조직의 위험 허용 수준을 완전히 알지 못합니다. CodeRabbit은 1차 필터와 보조 리뷰어로 사용하고, 최종 승인과 설계 판단은 사람이 담당합니다.

## 주의할 점

- 과도한 제안이 중요한 문제를 가릴 수 있습니다. `profile: chill`과 `path_filters`로 노이즈를 줄이세요.
- 정상 코드에 대한 오탐이 생길 수 있습니다. 테스트, 문서, 실제 요구사항으로 제안을 검증하세요.
- 가격과 플랜별 기능은 변할 수 있습니다. 현재 조건은 [공식 사이트](https://www.coderabbit.ai/)에서 확인하세요.
- 비밀 값이나 고객 데이터가 리뷰 컨텍스트에 들어가지 않도록 저장소와 연동 권한을 점검하세요.
